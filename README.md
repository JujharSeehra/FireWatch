Welcome to my NASA/Hack Club Stardance Challenge Project, FireWatch!

FireWatch is an early wildfire detection system that uses Arduino and Raspberry Pi. 
This system uses Flutter, Nginx, and Flask to run a web application available on any device connected to the same internet network as the FireWatch device.
This web application has the temperature and humidity surrounding the device on display, and also takes photos of the surrounding environment through the Raspberry Pi Camera 3. 

With the large amount of environmental disasters occurring more frequently, more and more devices and innovations are needed to help detect these threats and prevent damage and destruction. 
That is why I created FireWatch, to help combat these issues and improve safety in a hotter world.
