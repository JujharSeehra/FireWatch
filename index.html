FireWatch

Raspberry Pi Wildfire Detection System

Project Overview

FireWatch is an edge AI wildfire monitoring system built around a Raspberry Pi. Using environmental sensors and computer vision, the system continuously monitors its surroundings to estimate wildfire risk and alert users before dangerous conditions develop. Everything runs locally on the Raspberry Pi, reducing latency while allowing deployment in remote environments.

Features

Live Camera Feed

Takes continuous images of the environment surrounding the device

Temperature

Continuously monitors ambient temperature.

Humidity

Tracks environmental humidity levels.

Hardware

• Raspberry Pi 5 • Raspberry Pi Camera Module 3 • Temperature/Humidity Sensor (DHT 11) • Arduino Uno • Power Supply • Wireless Networking

System Architecture

Camera │ Environmental Sensors │ ▼ Arduino Uno │ ▼ Raspberry Pi │ Wildfire Risk Prediction │ Dashboard / Alerts
